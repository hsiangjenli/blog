# 📌 簡介

Office Viewer 是一個可以在 VSCode 中預覽、編輯文件（Excel、Word、PPT、Markdown、Zip、SVG 等等）的 Extension

<!-- more -->

# 🚀 介紹

## 什麼是 WYSIWYG？

> "What You See Is What You Get."

所見即所得，這是一種使用者介面設計理念與軟體功能，指你在編輯畫面（如文字、圖片、排版）上看到的最終效果，就會完全等於它列印、輸出或發布後的實際樣貌。目的是希望使用者可以更專注於內容的創作，而不需要花太多時間在排版上

## 使用

有分成「免費」與「付費」版，個人覺得免費版就已經很好用了，不過如果各位有能力可以付費的話，對於開發者是很棒的 Support！

![20260809145804](https://raw.githubusercontent.com/hsiangjenli/pic-bed/main/images/20260809145804.png)

### Markdown 預覽 + 編輯

最棒的是 Table 的功能！！！過去 Markdown 的表格常常為了要對有幾行幾列很麻煩，尤其是表格內有很多文字的時候會讓整個 Markdown 變得很混亂，而且可以直接在 Cell 內換行、在 Cell 內新增一層的 Table。唯一美中不足的是 Markdown 的 Table 還是不能直接在裡面新增 List 或是 Quote。至於其他的 Markdown 功能，像是調整字體顏色等等的就需要付費才能使用，自己是覺得還好，會使用 Markdown 主要就是希望可以越簡單越好，太多花俏的功能反而會讓 Markdown 變得很複雜

![20260809152214](https://raw.githubusercontent.com/hsiangjenli/pic-bed/main/images/20260809152214.png)

### PPT 預覽

可以在 VSCode 中直接預覽 PPT，但無法編輯

![20260809144514](https://raw.githubusercontent.com/hsiangjenli/pic-bed/main/images/20260809144514.png)

### Excel

可以預覽 + 編輯 Excel（可以有好幾個 sheet 切換）。 基本功能有 merge cell、修改顏色、修改字型、修改字體大小、修改對齊方式、修改欄位寬度、修改列高、排序、篩選、簡易的公式、自動換列等等

![20260809150203](https://raw.githubusercontent.com/hsiangjenli/pic-bed/main/images/20260809150203.png)

### SVG 預覽 + 編輯顏色

在 fontawesome 上下載一個 SVG，然後在 VSCode 中開啟，Office Viewer 會自動預覽。可以在右邊的「Preview」面版中直接修改顏色，並且可以匯出成 PNG 檔案！！！！
