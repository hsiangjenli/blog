[^ospo]: 開源辦公室 OSPO（Open Source Program Office）是什麼？

專門負責制定、管理及推動開源策略的單位。不只是「使用開源軟體」，而是能夠有制度、有策略地參與開源生態系

[^ospo-core]: OSPO 的核心工作有哪些？

https://ospoglossary.todogroup.org/ospo-definition/

工作領域 具體內容
開源治理（Governance） 建立開源軟體使用、審核與貢獻政策
授權合規（Compliance） 管理 MIT、Apache 2.0、GPL 等授權風險
軟體供應鏈（Security） 推動 SBOM、SCA 與開源元件風險管理
開源貢獻（Contribution） 建立員工提交 PR、回報 Issue 的流程
開源策略（Strategy） 決定哪些技術值得投資、貢獻或自行開源
社群經營（Community） 參與基金會、技術社群與開源活動

[^ospo-value]: OSPO 最重要的價值是什麼？

可分成三階段

1 2 3
Consume Contribute Lead
安全且合規地使用開源 向既有開源專案貢獻 主導專案與經營社群

不只是管理公司「用了哪些開源軟體」，而是思考：如何讓開源成為企業長期的技術能力、競爭優勢與外部合作資源
